# Legacy prototype (reference only)

This is the first prototype of CourtPass from the initial commit, kept only so each member can reuse ideas while porting their module into the MVC structure.

- It is **not** served by the app (blocked by `.htaccess`).
- It does **not** follow the revised proposal in places (NIC document upload, Parent/Player review tags, flat file structure).
- Once a module is fully ported, its old files here can be deleted by that module's owner.
